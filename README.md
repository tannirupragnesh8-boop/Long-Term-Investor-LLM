# Long-Term-Investor-LLM

This project started with a simple idea: can an LLM be trained to approach investing more like a long-term, value-oriented investor such as Benjamin Graham?

I used a few books written by Benjamin Graham to create my own custom dataset and fine-tuned a Qwen4 base model using the QLoRA method. The goal is to make the model better at understanding and responding to questions related to long-term and value investing based on the ideas and principles from the books.

This is still a work in progress. Right now, I have focused mainly on creating the dataset and fine-tuning the model. I am still working on adding more features and improving the project.

## Current Progress

Created my own custom dataset from selected Benjamin Graham books
Used QLoRA for parameter-efficient fine-tuning
Fine-tuned a Qwen4 base model
Built the initial setup for interacting with the fine-tuned model
More features and improvements are still being worked on
